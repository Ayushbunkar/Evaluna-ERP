# DASHBOARD INTEGRATION MATRIX

This matrix verifies that every dashboard, button, table, form, KPI, status, workflow and action is genuinely connected to the correct backend logic and real database state.

## Instructions for Verification

For each dashboard entry, verify the 15 checkpoints as outlined in the audit instructions:
1. Real data (no fake numbers, hardcoded metrics, or placeholder values)
2. API connection (correct tRPC query/mutation)
3. Database connection (underlying tables and queries)
4. Authorization (UI visibility and server-side validation)
5. Business logic (correct backend/service layer calculations)
6. Mutations (actual backend operations for important buttons)
7. State refresh (proper cache invalidation after mutations)
8. Loading state (proper loading indicators and disabled buttons)
9. Error state (graceful handling of validation, permission, business-rule, network, and server errors)
10. Empty states (proper handling of zero/empty data scenarios)
11. Filters (backend modification of queries, not just frontend filtering)
12. Pagination (backend pagination for large datasets)
13. Search (real backend data search where required)
14. Role visibility (role-appropriate information display)
15. Auditability (audit records for critical actions)

## Status Definitions
- **FULLY CONNECTED**: Passes all 15 verification checkpoints
- **PARTIALLY CONNECTED**: Connects to backend but missing some verification checkpoints
- **MOCK DATA**: Uses fake/static/demo data instead of real backend data
- **BROKEN**: Fails to connect properly or shows errors
- **UNUSED**: Dashboard exists but is not linked/accessible
- **DUPLICATE**: Duplicate functionality that should be consolidated
- **NEEDS TESTING**: Requires test coverage verification
